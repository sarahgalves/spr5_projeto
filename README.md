# spr5_projeto
Projeto de conclusão da sprint 5
Utilizando do arquivo vehicles.csv, foi feito uma análise dos dados representando-os em dois gráficos diferentes. Um histograma fazendo a relação entre a quantidade de carros e seus respectivos preços.
O segundo, se trata de um gráfico de dispersão fazendo uma relação entre preço, odômrtro e condição avaliada.
Ambas representações gráficas só são possíveis após o usuário apertar os botões disponíveis na interface.
